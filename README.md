# 한칸 (HANKAN)

**HAN:KAN**은 Windows PC의 폴더를 웹 기반 파일 저장·공유 공간으로 사용하는 학교 프로젝트다. 관리자는 저장 위치와 용량을 정하고, 승인된 사용자는 VIEWER 또는 OWNER 권한으로 파일을 이용한다. 파일은 링크로 공유하거나 관리자가 공개 목록에 게시할 수 있다.

계정·권한 검사, 파일 저장 암호화(AES-256-GCM), Windows DPAPI 키 보호, 공유 만료·취소와 변조 감지를 구현했다. 서버를 운영하는 관리자에게도 파일 내용을 숨기는 종단간 암호화 서비스는 아니다.

## Windows에서 실행

1. [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)을 설치한다.
2. 저장소를 내려받은 뒤 PowerShell에서 다음 명령을 실행한다.

   ```powershell
   dotnet run --project .\src\HANKAN.Web\HANKAN.Web.csproj
   ```

3. 서버 PC에서 `http://127.0.0.1:5180/`을 연다. 콘솔에 표시된 일회용 설정 코드를 입력하고 관리자 이메일·비밀번호, 비어 있는 전용 저장 폴더의 **Windows 절대 경로**, 전체 용량 한도를 지정한다.
4. 관리자 로그인 후 사용자는 계정을 만들고 VIEWER 또는 OWNER 권한을 신청할 수 있다. 관리자가 승인하면 공용 저장소의 폴더를 탐색하고 파일을 내려받을 수 있다. 파일과 폴더를 다중 선택해 하위 항목까지 ZIP으로 받을 수 있다. 관리자와 OWNER는 폴더 생성, 파일 업로드, 이름 변경, 드래그 또는 목적지 창으로 이동, 삭제 영향 확인 후 하위 항목까지 영구 삭제할 수 있다.

앱은 Windows 루프백 주소에서만 수신한다. 다른 기기에서 접속하려면 최초 설정을 완료한 뒤 별도의 HTTPS 연결 경로를 구성해야 한다. 브라우저에서 복사한 공유 주소는 현재 접속한 주소를 사용한다.

계정·설정·SQLite 데이터베이스 `hankan.db`는 실행한 Windows 계정의 `%LOCALAPPDATA%\HANKAN`에 저장된다. 업로드 파일은 최초 설정에서 지정한 폴더에 암호화되어 저장된다. 기존 데이터를 유지하려면 **같은 Windows 계정의 앱 데이터 폴더와 파일 저장 폴더를 함께 보관**해야 한다. 둘 중 하나를 잃거나 다른 PC로 옮기면 파일에 접근하지 못할 수 있다.

기존 설치를 새 버전으로 실행하면 데이터베이스가 v5에서 v6으로 자동 변경된다. 업데이트 전 앱을 종료하고 `%LOCALAPPDATA%\HANKAN`의 `hankan.db`·`instance.marker`와 설정에서 지정한 암호문 저장 폴더를 **같은 시점에 함께 백업**한다. 복원할 때도 앱을 종료한 뒤 이 세 항목을 같은 백업본으로 되돌린다.

2026-10-04 격리 시험에서 28개 시나리오 중 21개가 통과했고 7개는 일부 조건만 확인했다. 남은 조건은 DB와 표식 동시 소실, 삭제 실패 시 사용량 정산, Windows 시스템 임시 폴더 잔존, 잘못된 전송 길이·디스크 부족, 별도 기기 브라우저 전송 전 과정, 모든 화면 상태의 모바일·키보드 조작이다.

이 저장소는 수업 시연을 위한 첫 버전의 소스 코드다. 상시 인터넷 서비스로 운영하기 위한 배포·백업·보안 점검 절차는 제공하지 않는다.
